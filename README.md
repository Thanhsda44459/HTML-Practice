# HTML Practice

A responsive landing page built with HTML5, SCSS, and the 7-1 architecture pattern. This project demonstrates modern CSS preprocessing, component-based HTML structuring, and responsive web design.

## Tech Stack

- **HTML5** — Semantic markup
- **SCSS / Sass** — CSS preprocessor with 7-1 pattern architecture
- **Parcel** — Zero-config bundler
- **PostHTML** — HTML component includes

## Features

- Responsive design (mobile, tablet, desktop)
- SCSS 7-1 pattern (`abstracts/`, `base/`, `components/`, `layouts/`)
- Reusable HTML components via PostHTML includes
- Parcel-based dev server with hot reload

## Project Structure

```
src/
├── assets/            # Images, fonts, icons
├── components/        # Reusable HTML partials (nav, cards, etc.)
├── layouts/           # Page layout templates
├── pages/             # HTML pages (index.html)
└── stylesheets/       # SCSS files (7-1 pattern)
    ├── abstracts/     # Variables, mixins, functions
    ├── base/          # Reset, typography
    ├── components/    # Component styles
    └── layouts/       # Layout styles
```

## Getting Started

```bash
# Clone the repo
git clone https://github.com/Thanhsda44459/HTML-Practice.git

# Install dependencies
npm install

# Start dev server
npm start
```

Open [http://localhost:1234](http://localhost:1234) in your browser.
